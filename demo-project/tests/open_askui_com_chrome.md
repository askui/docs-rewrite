# Open askui.com in Chrome

Run this on the **Chrome Browser** device.

## Preconditions
- The Chrome browser device is connected (Playwright launches the window).

## Steps
1. Navigate to `https://www.askui.com`.
2. Wait until the page has fully loaded.
3. Accept the cookie banner if one appears.

## Postconditions
- Test passes if the askui.com homepage is visible (the AskUI logo and the main
  navigation are shown).
