# Open Notepad on Windows

Run this on the **Windows Desktop** device.

## Preconditions
- The Windows desktop is visible and no Notepad window is already open.

## Steps
1. Open the Start menu (press the Windows key).
2. Type `Notepad`.
3. Press Enter and wait until the Notepad window opens and is focused.

## Postconditions
- Test passes if an empty Notepad window is visible in the foreground.
