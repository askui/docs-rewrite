## Authentication

| Variable | Description |
|----------|-------------|
| `ASKUI_WORKSPACE_ID` | Your workspace identifier. Required when using the AskUI Hub as the model provider. |
| `ASKUI_TOKEN` | Your workspace access token. Required when using the AskUI Hub as the model provider. See [Workspaces](/docs/account-billing/workspaces). |

## Model of a CLI run

The CLI reads the first three for a run with
[your own model](/docs/running-tests/cli#model-options), and the image edge for every run,
AskUI Inference included. A flag wins over each of them, and so does a setting of AskUI Desktop.
`askui run --help` lists them under **Environment**. AskUI Desktop does not
read them: it takes the model from its Settings.

**`VLM_PROVIDER_MODEL_ID`** — the model of your own provider, when neither
`--model-id` nor the app's Settings name one.

**`ANTHROPIC_API_KEY`** — the API key for `--model-provider anthropic`, when
no credential flag is set.

**`OPENAI_API_KEY`** — the API key for `--model-provider openai`, when no
credential flag is set. A run against an endpoint of your own takes no key
from this variable.

**`ASKUI_VLM_MAX_IMAGE_EDGE`** — the longest edge of a screenshot sent to the
model, in pixels. The default is 1024.

## AgentOS connection

| Variable | Default | Description |
|----------|---------|-------------|
| `ASKUI_CONTROLLER_CLIENT_SERVER_AUTOSTART` | `true` | Set to `false` to prevent the CLI from starting a local AgentOS instance automatically. Use this when connecting to a remote AgentOS. |
| `ASKUI_CONTROLLER_CLIENT_SERVER_ADDRESS` | `localhost:23000` | Address of the AgentOS gRPC server to connect to. Override when using a remote AgentOS instance. |

## Devices on this computer

AskUI Desktop and the CLI read these when they look for a device's tools.
`askui run --help` lists them under **Environment**.

**`ASKUI_ADB_PATH`** — the `adb` to use, in place of the one in the Android SDK
or on `PATH`. An `adb` found this way counts as installed, see
[Android phone](/docs/devices/android-phone#no-adb-on-this-computer).

**`ASKUI_IDP_API_KEY`** — the API key for remote VMs on the IDP platform, when
the app's Settings hold none.

**`ASKUI_IDP_BASE_URL`** — the IDP API, in place of the configured one.

**`ASKUI_IDP_CONSOLE_URL`** — the IDP console the remote VMs open in, in place
of the configured one.
