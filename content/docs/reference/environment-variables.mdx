## Authentication

| Variable | Description |
|----------|-------------|
| `ASKUI_WORKSPACE_ID` | Your workspace identifier. Required when using the AskUI Hub as the model provider. |
| `ASKUI_TOKEN` | Your workspace access token. Required when using the AskUI Hub as the model provider. See [Workspaces](/docs/account-billing/workspaces). |

## AgentOS connection

| Variable | Default | Description |
|----------|---------|-------------|
| `ASKUI_CONTROLLER_CLIENT_SERVER_AUTOSTART` | `true` | Set to `false` to prevent the CLI from starting a local AgentOS instance automatically. Use this when connecting to a remote AgentOS. |
| `ASKUI_CONTROLLER_CLIENT_SERVER_ADDRESS` | `localhost:23000` | Address of the AgentOS gRPC server to connect to. Override when using a remote AgentOS instance. |

## Settings

```bash
ASKUI_GLOBALMODEL__MODELID=claude-opus-5-5 askui run --plan smoke
```

Every setting has a variable: `ASKUI_` and the setting's key in capitals, with
`__` between the levels. It wins over the stored value in AskUI Desktop and in
the CLI. [Configure the CLI](/docs/running-tests/cli-configuration#settings)
lists every setting, and `askui run --help` every variable.

Some settings also answer to an earlier name:

**`ASKUI_ADB_PATH`**: `setup.android.adbPath`, the `adb` to use, in place of
the one in the Android SDK or on `PATH`. An `adb` found this way counts as
installed, see
[Android phone](/docs/devices/android-phone#no-adb-on-this-computer).

**`ASKUI_CONTROLLER_PATH`**: `setup.agentOs.controllerPath`, the AgentOS
Controller to start for a desktop on this computer.

**`ASKUI_INFERENCE_ENDPOINT`**: `inference.endpoint`, the AskUI Inference
API.

**`ASKUI_LICENSE_KEY`**: `license`, the local license key.

**`ASKUI_IDP_API_KEY`**: `idp.apiKey`, the API key for remote VMs on the IDP
platform.

**`ASKUI_IDP_BASE_URL`**: `idp.endpoint`, the IDP API.

**`ASKUI_IDP_CONSOLE_URL`**: `idp.consoleUrl`, the IDP console the remote VMs
open in.

`ASKUI_NUGET_TIMEOUT_SECONDS` no longer works. Set
`ASKUI_CUSTOMTOOLS__NUGETTIMEOUTMS`, in milliseconds.
