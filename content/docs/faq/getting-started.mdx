### How do I get started?

Follow the [Quickstart](/docs/quickstart) — it takes under 10 minutes and
covers account creation, installation, and running a first test.

### Do I need to write code?

No. Tests are written in plain Markdown. There is no API to learn and no
programming language required.

### Can I try AskUI for free?

Yes. Sign up at the [AskUI Hub](https://hub.askui.com) to start a free trial
with full feature access.
