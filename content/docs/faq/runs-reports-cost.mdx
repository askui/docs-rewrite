### What is the difference between a failed and a broken status?

- **`FAILED`**: a proven defect. The agent's action reached the right
  target, and the application answered wrongly or not at all: a value was
  wrong, a transition did not happen. Investigate the app.
- **`INCONCLUSIVE`**: the agent could not tell whether the application
  behaved as expected, for example because it did not find a page or an
  element. The reason names what was missing and where it looked. Name the
  path in the device profile or the test.
- **`BROKEN`**: the run could not complete a step due to an infrastructure or
  environment issue: AgentOS unreachable, step limit reached, model error, or
  network timeout. Investigate the environment, not the app. Check the
  [Troubleshooting guide](/docs/troubleshooting) first.
- **`WARNING`**: the step completed but something unexpected was noted. The run
  continues.

See [Test statuses](/docs/results/test-statuses) for all seven statuses.
