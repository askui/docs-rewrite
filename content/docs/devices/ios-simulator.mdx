An **iOS simulator** profile provisions an Apple simulator.

<Callout type="warn" title="macOS only">
Apple ships the simulator exclusively with Xcode on a Mac. On Windows this
kind is greyed out in the Add-profile dialog, running AskUI Desktop on
Windows cannot drive an iOS simulator, not even a remote one.
</Callout>

**Preconditions:** a Mac running AskUI Desktop, the full Xcode (the
command-line tools alone are not enough), and `idb_companion`. Both come from
Apple and Homebrew, so you install them yourself: Xcode from the App Store,
then in a terminal:

```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer && sudo xcodebuild -license accept
brew tap facebook/fb && brew trust facebook/fb && brew install idb-companion
```

While one is missing, the device row reads **Set up**, and its dialog shows
these steps with a copy button. The **iOS Simulators** card under
**Settings → This machine** shows them too.

## Use an existing simulator

The **Devices** page does not list the simulators Xcode already has: there is one
per device type and runtime, often dozens. To use one of them:

1. **Add device** → **An iPhone**.
2. Under **Use a simulator from this Mac**, click **Use this simulator** next to it.

AskUI Desktop can then start and stop that simulator, and never deletes it.

## Create it

1. **Add device** → **iOS simulator**.
2. Fill in the fields:
   - **Device type**: the iPhone / iPad model to simulate *(select, default `iPhone 15`)*
   - **Runtime**: the iOS version; empty picks the newest installed *(select, optional)*
   - **Lifecycle**: same semantics as the [Android emulator](/docs/devices/android-emulator#create-it) *(select, default `Persistent`)*
3. **Add device**.

## Run it

1. **Start**: the simulator is created on first use and booted; later
   Starts reuse it.
2. Pick the profile in the test's **Run on** dropdown and press **Run**.
