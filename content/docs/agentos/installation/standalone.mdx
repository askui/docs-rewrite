Install AgentOS locally in standalone mode, it runs as a regular process in
your user session. This is the fastest way to get going on a development
machine.

<Callout title="Note">
AgentOS is proprietary software, **free for non-commercial use**. For
commercial deployments a license is required, see
[pricing](https://www.askui.com/enterprise) for details.
</Callout>

## Prerequisites

- **Windows**: **macOS**, or **Linux**, see
  [System Requirements](/docs/agentos/reference/system-requirements) for supported
  versions.
- **macOS only:** grant **Accessibility** and **Screen Recording** permissions
  to the app running AgentOS, under **System Settings → Privacy & Security**.

## Install

<Callout title="More install channels coming soon">
AgentOS will soon be available through additional channels (such as a NuGet
package). For now, we recommend installing it via `pip`.
</Callout>

On macOS, the quickest way to install AgentOS today is with `pip`:

```bash
pip install askui-agent-os
```

If you want to use AgentOS with the AskUI Desktop App, point the app at the
installed binary:

<Steps>
<Step>
Open **Settings** in AskUI Desktop and go to **This machine**.
</Step>
<Step>
Under **AgentOS**, paste the path to the installed controller. For a `pip`
install it looks like:

```
~/py-env/lib/python3.12/site-packages/askui_agent_os/bin/AskuiRemoteDeviceController
```
</Step>
</Steps>
