Install AgentOS locally in standalone mode, it runs as a regular process in
your user session. This is the fastest way to get going on a development
machine.

<Callout title="Note">
AgentOS is proprietary software, **free for non-commercial use**. For
commercial deployments a license is required, see
[pricing](https://www.askui.com/enterprise) for details.
</Callout>

## Prerequisites

- **Windows** (x64 or ARM64), **macOS** on Apple silicon, or **Linux** (x64 or
  ARM64) with an **X11** session, Wayland is not supported, see
  [System Requirements](/docs/agentos/reference/system-requirements) for supported
  versions.
- **macOS only:** grant **Accessibility** and **Screen Recording** permissions
  to the app running AgentOS, under **System Settings → Privacy & Security**.

## Install

There is no installer to run: unpack the archive into a folder of your choice
and point AskUI Desktop at the controller inside it.

<Steps>
<Step>
**Unpack the ZIP into its own folder.** The archive has no top-level folder,
its files land directly where you extract it, so create a dedicated folder
first, for example:

| Platform | Folder |
|---|---|
| Windows | `C:\Users\<you>\AskUI\AgentOS` |
| macOS | `/Users/<you>/AskUI/AgentOS` |
| Linux | `/home/<you>/AskUI/AgentOS` |

Keep the folder's contents together: the controller loads the folders next to
it, such as `Configs`.
</Step>
<Step>
**Copy the path to the controller.** Inside that folder, find the
`AskuiRemoteDeviceController` executable and copy its full path:

- **Windows:** Shift + right-click `AskuiRemoteDeviceController.exe` and choose
  **Copy as path**. Windows wraps the path in quotes, remove them when you
  paste.
- **macOS:** right-click `AskuiRemoteDeviceController`, hold **Option** and
  choose **Copy "AskuiRemoteDeviceController" as Pathname**.

With the example folders above, the path is:

```
C:\Users\<you>\AskUI\AgentOS\AskuiRemoteDeviceController.exe
```

```
/Users/<you>/AskUI/AgentOS/AskuiRemoteDeviceController
```
</Step>
<Step>
**Point AskUI Desktop at it.** Open **Settings** in AskUI Desktop, go to
**This machine**, and paste the path under **Agent OS → Controller path**.
Use the full path, `~` is not expanded. The change applies on the next device
connect, no restart needed.
</Step>
</Steps>

<Callout title="Linux">
AskUI Desktop runs on Windows and macOS. On a Linux machine, start
`AskuiRemoteDeviceController` from the unpacked folder in an **X11** session
(Wayland is not supported) and drive it from AskUI Desktop as a
[Remote computer](/docs/devices/remote-computer).
</Callout>
